# Labs

Runnable, self-contained demos. One directory per lab.

Each lab has a README stating:

- **Prerequisites** — what must be installed or authed first
- **Steps** — the actual commands
- **Expected output** — what success looks like
- **Takeaway** — the homework version for participants

## The rule

A lab may only be built from cards marked `ran-it`. If a step is only `docs` or `inferred`, go run it and upgrade the card first.
