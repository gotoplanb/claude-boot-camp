# Claude Boot Camp

A hands-on curriculum for leading Claude adoption — for center-of-excellence leads inside companies, and for consultants and systems integrators doing the integration work, with an emphasis on Salesforce.

Published at [davestanton.com/claude](https://davestanton.com/claude).

## Format

One hour per topic, three beats:

1. **Lecture** — the why and the context, kept short.
2. **Lab** — live implementation. Real commands, real failures.
3. **Takeaway** — homework, so you do it yourself.

The demo is one path, not the path. How I work isn't how you'll be most productive; the takeaway is where you find your own.

## Sections

1. Foundational AI and concepts
2. Operating Claude products
3. Administering Claude products
4. Integrating with Claude (MCP and APIs)
5. Building with Claude Code
6. Claude + Salesforce

See [curriculum.md](curriculum.md) for the working outline.

## How it's built

Cards first, prose later — the same method behind [Geography as Destiny](https://github.com/gotoplanb/geography-as-destiny). Ideas, demos, gotchas, and product behaviors get filed in [`cards/`](cards/) as they're encountered. Once there's enough material in an area, the section gets written from the cards, and rewritten again as more accumulate.

Every card records **how it was learned** — whether it was actually run, read in docs, or inferred. Labs are built only from things that were actually run. This is a curriculum being built by learning in the open, and the notes say so.

## Layout

```
cards/        numbered reference cards, filed as encountered
sections/     the six sections; prose synthesized from cards
labs/         runnable, self-contained demos
curriculum.md the working outline
CHANGELOG.md  version history
```
